# 상담시뮬레이션톡

예비 교사를 위한 법률 대처 상담 훈련 프로그램입니다. 가상의 학생·학부모가 톡이나 음성으로 말을 걸면 제한 시간 안에 답하고, 그 답이 법적으로 안전했는지 조문·판례와 함께 바로 첨삭받습니다.

**바로 열기: https://zzangusz-art.github.io/sangdam-simtalk/**

설치할 것이 없고 서버로 보내는 정보도 없습니다. 훈련 기록은 쓰는 사람의 브라우저에만 저장됩니다.

## 들어 있는 것

- **상담 시나리오 26개(100턴)**: 학부모 15개, 학생 11개. 상대(학생/학부모), 학교급(초/중/고), 전공 11개로 고릅니다.
- **응답 방식**: 선택지 고르기, 직접 입력(키워드 보조 분석).
- **음성 모드**: 상대의 말을 소리로 듣고 마이크로 답할 수 있습니다. Chrome이나 Edge에서 됩니다.
- **말실수 사전 48쌍과 10문항 퀴즈**: 위험한 말과 같은 뜻의 안전한 말을 짝지었습니다.
- **법률 근거 72건**: 법령 35, 고시·지침 11, 판례·결정 13, 사건 10, 통계 3건. 카드마다 출처 링크가 있습니다.
- **결과 리포트**: 점수, 역량 4축, 턴별 첨삭, 상담 직후 할 일 체크리스트.

법령과 판례는 2026년 11월 기준입니다. 근거 전체와 확인하지 못한 항목은 [리서치_법률근거.md](리서치_법률근거.md)에 정리했습니다.

## 주의

교육·훈련용 자료이며 법률 자문이 아닙니다. 같은 말이라도 맥락, 반복성, 학생의 연령과 상태에 따라 법적 평가는 달라집니다. 실제 사안은 학교 관리자, 교육청 교육활동보호센터(1395), 변호사와 상의하세요. 등장하는 인물과 대화는 실제 사례 유형을 바탕으로 만든 가상입니다.

## 고쳐 쓰기

Node.js만 있으면 됩니다.

```
node build.mjs      # src/ 를 합쳐 index.html, 상담시뮬레이션톡.html, 리서치_법률근거.md 를 만든다
node validate.mjs   # 시나리오·근거 데이터 점검
```

- `src/data-1-laws.js` 법률 근거 카드
- `src/data-2-parent-*.js`, `src/data-3-student-*.js` 시나리오
- `src/data-4-phrases.js` 말실수 사전
- `src/app.js`, `src/app.css` 화면과 엔진

법령이 바뀌면 해당 근거 카드와 그 카드를 쓰는 시나리오의 첨삭 문구, `src/data-0-core.js`의 기준일을 고친 뒤 다시 빌드합니다.
